# 朋友圈海报智能体｜客户部署源码包

这是一个可独立部署的网页版朋友圈海报智能体。客户把本压缩包交给自己的 AI Agent，并告诉 Agent：

> 请先完整阅读根目录 `AGENT_DEPLOY.md` 和 `CUSTOMER_CONFIGURATION.md`，然后使用我的 EdgeSpark 账号创建一个全新的项目，按文档部署。所有密钥都通过 EdgeSpark 安全填写页面让我本人填写，不要让我把密钥发到聊天或写进代码。

## 主要功能

- 两种创作入口：输入朋友圈文案后由 DeepSeek 推理方案，或直接描述想要的图片。
- 生活类、营销类海报；营销类支持产品、Logo、人物参考图和二维码安全留白。
- Image2 一次生成完整画面、人物、中文文字和排版，不采用“底图加文字”的二次合成。
- 异步生成、失败原因提示、安全重试、作品历史、高清下载和参考素材复用。
- 邮箱注册（默认不要求邮件验证）、用户隔离、每位用户独立加密保存自己的 DeepSeek / Image2 Key。
- 年费权限、暗号免年费、微信支付接口，以及左右结构的运营管理后台。
- 管理员数据面板、用户列表、生成记录、成功/失败状态、暗号管理和新手教学视频管理。

## 这个包不包含什么

本包不包含交付方现有的以下内容：

- EdgeSpark 项目 ID、生产域名或平台登录状态；
- 任何 `.env`、API Key、商户密钥、OSS 密钥、私钥或证书内容；
- 现有用户账号、用户填写的 DeepSeek / Image2 Key、作品、生成记录或数据库；
- 构建缓存、`node_modules`、本地 EdgeSpark 状态、生产构建产物；
- 原站点的微信域名验证 TXT 文件。

客户部署后会得到一个数据库、存储桶、用户系统和域名完全独立的新项目。

## 客户需要准备

最低可用版本只需要：

1. 一个 EdgeSpark 账号；
2. 一个用于首位管理员的邮箱；
3. 客户自己的 DeepSeek API Key 和 Image2 API Key（部署后在网页“服务设置”中填写）；
4. 两个由 Agent 现场生成的 32 字节随机密钥，随后由客户本人填入 EdgeSpark 安全页面。

如果要开放付费，还需要客户自己的微信支付商户资料；如果要使用后台“新手教学”视频上传，还需要客户自己的阿里云 OSS Bucket 和 RAM 密钥。完整字段见 `CUSTOMER_CONFIGURATION.md`。

## 默认商业规则

- 年费：800 元/年；
- 输入管理员生成的暗号：免年费；
- 微信支付：源码支持，但新部署默认应先保持关闭，配置并验收客户自己的商户资料后再开启；
- 用户调用 DeepSeek 和 Image2 的费用：由用户自己的 API Key 对应账户承担。

如需修改价格、品牌、域名、注册规则或支付方式，请先让 Agent 阅读项目 `AGENTS.md` 和设计系统，再做全链路修改与测试。

## 技术结构

- 前端：React + Vite；
- 后端：EdgeSpark Worker + Hono；
- 数据库：EdgeSpark 托管数据库，Drizzle schema/migrations；
- 图片与用户参考素材：EdgeSpark Storage；
- 新手教学视频：可选阿里云 OSS 直传；
- 推理：DeepSeek；
- 海报生成：Image2 Open API。

## 给非技术客户的最短操作

1. 解压本包；
2. 把解压后的整个文件夹交给 Agent；
3. 把本页开头那段话发给 Agent；
4. Agent 需要登录或填写密钥时，会给你一个安全网页链接；你只在那个网页里填写；
5. Agent 完成后，应交付新站地址、管理员账号、功能验收结果和未配置的可选项。

详细部署顺序、命令和验收标准全部写在 `AGENT_DEPLOY.md`。
