# Page overrides

The project has no page-level exceptions yet. Use `../MASTER.md` exclusively.

When a real exception is needed, create `<route-name>.md` here and document:

1. the exact master rule being overridden;
2. the product reason;
3. the replacement token or behavior;
4. responsive and accessibility handling.

Page overrides may not redefine the brand palette, type family, lime primary CTA, Lucide icon family or accessibility minimums.
